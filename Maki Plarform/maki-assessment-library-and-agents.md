# Maki Assessment Library And Agents

## Assessment philosophy

Maki positions its assessment system around the idea of measuring what truly drives job success across one unified flow. The library is described as covering:

- soft skills
- hard skills
- cognitive skills
- language skills

The emphasis is on multi-format assessment rather than single-format testing.

## Assessment formats

Maki highlights the following formats:

- immersive assessments using realistic job scenarios
- conversational tests driven by AI dialogues
- situational judgement tests
- free-answer formats in written or spoken form
- audio and video questions
- hard coding challenges

## Skill coverage

Maki states that it can assess `400+ skills`.

Referenced skill categories include:

- soft and behavioural skills
- cognitive aptitudes
- job-specific competencies
- language proficiency
- technical expertise

Examples include:

- communication
- collaboration
- adaptability

- numerical reasoning
- learning agility

- industry-specific capabilities

## Ken: Deep Assessment

`Ken` is positioned as Maki’s late-funnel, high-stakes assessment capability.

### Core positioning

- built for defensible assessments
- aimed at hires where legal, compliance, and decision confidence matter
- modular and role-calibrated
- built around `400+ skills`

### Main features

- long-form structured assessments
- role-calibrated rubrics derived from job analysis and outcome data
- multi-format evaluation
- coding challenges in Java, Python, Node, C#, and SQL
- case simulations
- personality modules using the Compass personality framework
- AI-assisted scoring benchmarked against expert human raters
- audit-ready outputs with traceable evidence

### Assessment depth

Ken supports:

- advanced cognitive tests
- long-form coding challenges
- system design
- complex problem solving
- case studies
- simulations
- advanced behavioral assessment
- leadership assessment

### Intended use cases

Ken is positioned as best suited for:

- engineering
- data
- corporate roles
- finance
- consulting
- leadership hiring
- graduate programs

### Claimed outcomes

- higher predictive validity across roles
- fewer mis-hires
- stronger retention
- consistent global evaluation standards

## Shiro: Skills Screening

`Shiro` is positioned as the short-assessment engine for high-volume hiring.

### Core positioning

- replaces résumé screening with science-backed assessments
- designed for early-funnel speed and predictive power
- optimized for scale without losing structure

### Main features

- around `15 minutes` per candidate
- multi-format tasks including simulations, interactive Q&A, coding challenges, and audio/video inputs
- configurable eligibility checks
- customizable question sets
- support for `45+ languages` across `100+ markets`
- ATS-triggered workflow
- fully branded user experience
- bias-audited AI scoring

### Claimed outcomes

- `3x` faster time-to-hire
- `30%` lower turnover
- `250,000+` recruiter hours saved

### Workflow summary

- candidate applies and enters the ATS
- Shiro triggers automatically
- candidate completes a short skills assessment
- results appear instantly in Maki Recruiter
- ATS status or tags update automatically
- candidates above threshold move forward

Across the library and its named agents, Maki’s value proposition is structured around:
