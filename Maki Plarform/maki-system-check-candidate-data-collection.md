# Maki System Check: Candidate Data Collection

## Purpose

Maki’s `System-check` feature is used to verify whether a candidate’s home IT setup is compatible with remote work requirements.

The purpose is to confirm that the candidate has the necessary:

- network conditions
- system environment
- hardware capacity

## Data collected by System-check

### 1. Network

The feature may collect:

- download speed
- upload speed
- network latency
- network connection type

Example reference values mentioned in the source material:

- download speed: `20 Mbps`
- upload speed: `6 Mbps`
- network latency: `100 ms`
- wired connection preferred

### 2. System

The feature may collect:

- operating system
- browser version

Example reference values mentioned:

- `MacOS 11` or higher
- `Chrome 23` or higher

### 3. Hardware

The feature may collect:

- machine type
- screen resolution
- processor cores
- processor type / clock speed
- free HDD space
- RAM

Example reference values mentioned:

- desktop or laptop
- `1440 × 900` screen resolution
- `4` processor cores
- `1.8 GHz`
- `20 GB` free disk space
- `2 GB` RAM

## Data storage and privacy

The source material states that privacy and data security are treated as a priority.

Candidates who have concerns about how system-check data is stored can request deletion by contacting:

- `privacy@makipeople.com`

## Candidate guidance context

The source material also notes that candidates may be provided with instructions, including a video, on how to complete the system check and application installation process.
