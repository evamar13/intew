# Maki Document Upload Limitations

## Purpose

This document summarizes the technical constraints described for Maki document-upload activities.

## Core rule

When an assessment includes a document-upload task, the candidate must submit the file directly through the Maki platform. The help material emphasizes that the most common causes of failure are:

- unsupported file type
- file size above the limit

## 1. File size limit

The maximum accepted size per upload is:

- `500 MB`

Files larger than this limit are rejected.

## 2. Number of files per question

Each upload question accepts:

- `one file only`

If multiple documents are required, candidates are expected to combine them into a single file before uploading, such as:

- a ZIP archive
- a multi-page PDF

## 3. Accepted file formats

### Documents

- PDF
- Word `.doc`
- Word `.docx`
- OpenDocument Text `.odt`

### Spreadsheets

- Excel `.xls`
- Excel `.xlsx`
- OpenDocument Spreadsheet `.ods`

### Presentations

- PowerPoint `.ppt`
- PowerPoint `.pptx`
- OpenDocument Presentation `.odp`

### Data files

- CSV

### Archives

- ZIP
- RAR

## 4. Non-accepted formats

The help article states that images and all other unlisted file types are not accepted.

Examples specifically mentioned:

- `.jpg`
- `.png`
- `.gif`
- `.mp4`
- `.mp3`

## Support contact

For help with upload issues, the article directs users to:
