# Newsroom Media Access Reference

## Media Registration

Accredited journalists can register to get advance notice of OECD events, reports, and statistics.

## Report Access

For publications under embargo and for access to all other OECD publications, journalists are instructed to send a message to:

- `embargo@oecd.org`

## Embargo Rules

By registering, journalists commit to comply with OECD embargo rules:

- no broadcast before the official release time
- no print publication before the official release time
- no news wire transmission before the official release time
- no internet transmission of text or information before the official release time
- no communication or comment to any outside party before the stated official release time

## Why This Matters

This is a core media-operations layer:

- advance-notice management
- controlled pre-release circulation
- compliance with release timing
- support for coordinated media coverage
