# Newsroom Press Launches Reference

## Function

Press launches sit between publications, events, and media relations. They package a release moment into a coordinated communications event.

## Example Listed On The Newsroom Page

- `OECD Economic Outlook-Regional Presentations`
  Labels:
  - `Press launch`
  - `Publication launch`
  - `Virtual`
  - `Webinar`
  Date: `3 June 2026`

## Classification Note

This format belongs in `Media/Press` because it is designed to stage media-facing release moments, even when the underlying asset is a publication or event.
