# Newsroom Overview Reference

## Core Structure

The Newsroom page functions as the OECD's central media-facing entry point.

Main elements visible on the page:

- `Newsroom`
- `Contact`
- `Multimedia gallery`
- language options: `English`, `francais`, `espanol`
- search prompt: `Find relevant news`
- search use case: `Search for a topic, country or event`
- `Media registration`

## Media Registration Positioning

Accredited journalists can register to get advance notice of OECD events, reports, and statistics.
