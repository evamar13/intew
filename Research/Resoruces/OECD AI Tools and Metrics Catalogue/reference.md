# OECD AI Tools And Metrics Catalogue

## Main page

- `https://oecd.ai/en/`

## Purpose

The OECD.AI catalogue is presented as a one-stop-shop for tools and metrics that help AI actors build and deploy AI systems that are safer, more secure, and more trustworthy.

## Main resource folders

- `Tools`
- `Metrics`

## Grouping rule

All tool-related shortcut folders are grouped under `Tools`.

All metric-related shortcut folders are grouped under `Metrics`.
