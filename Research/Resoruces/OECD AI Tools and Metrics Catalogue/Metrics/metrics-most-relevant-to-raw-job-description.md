# Metrics Most Relevant To The Raw Job Description

Source files:

- metrics export: `117ojp1rjqpmsoty1g9-metrics-export.xlsx`
- role description: `OECD comunications to me/raw-offer.md`

This shortlist does not try to reproduce the entire export. It isolates the metrics that best bridge the OECD role and the AI-evaluation catalogue: answer quality, groundedness, agent performance, safety, fairness, privacy and explainability.

| Metric | Definition | How it is calculated | Why it matters for the role | Reference URL |
| --- | --- | --- | --- | --- |
| Accuracy | Overall correctness of predictions. | Correct predictions / total predictions. | Useful as a basic baseline when evaluating automated classifiers or scoring systems in AI-mediated communication workflows. | https://en.wikipedia.org/wiki/Accuracy_and_precision |
| Precision | How reliable positive predictions are. | True positives / (true positives + false positives). | Important when false alarms are costly, for example flagging misinformation, low-quality content, or irrelevant AI referrals. | https://en.wikipedia.org/wiki/Precision_and_recall |
| Recall | How many true positives the system manages to capture. | True positives / (true positives + false negatives). | Important when missing important items is costly, for example failing to detect relevant citations, mentions, or unsafe outputs. | https://en.wikipedia.org/wiki/Precision_and_recall |
| F-score | Single measure that balances precision and recall. | Usually F1 = 2PR / (P + R). | Useful when neither false positives nor false negatives should dominate the evaluation. | https://en.wikipedia.org/wiki/F-score |
| Receiver Operating Characteristic Curve (ROC) and Area Under the Curve (AUC) | Classifier performance across all decision thresholds. | ROC plots true positive rate against false positive rate; AUC summarizes the full curve. | Helpful for understanding threshold trade-offs in automated screening, scoring, or classification workflows. | https://developers.google.com/machine-learning/crash-course/classification/roc-and-auc |
| Factual Correctness | Whether an answer is factually right. | Typically scored by checking generated claims against verified reference material or gold answers. | Highly relevant for public-facing AI summaries, policy communications, and answer engines where factual accuracy is critical. | https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/factual_correctness/ |
| Faithfulness | Whether the answer stays grounded in the provided source material. | Typically judged by testing whether each claim in the answer is supported by the retrieved context. | Very relevant for AI-generated summaries of OECD publications, reports, and data. | https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/ |
| Response Relevancy | Whether the response actually answers the query. | Typically measured by semantic comparison between the user request and the model response. | Relevant to generative search, LLM referrals, and AI-mediated discoverability work. | https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/answer_relevance/ |
| Context Precision | How much of the retrieved context is actually useful. | Relevant retrieved context / total retrieved context. | Useful when analysing retrieval systems that surface OECD reports, policy briefs or statistics into AI answers. | https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/context_precision/ |
| Context Recall | How much of the needed context was retrieved. | Necessary context retrieved / total necessary context. | Useful when evaluating whether an AI system finds enough supporting OECD material before generating an answer. | https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/context_recall/ |
| Context Entities Recall | How well key entities from the source are preserved or retrieved. | Typically measured as the share of important source entities recovered in the retrieved context or answer. | Relevant for preserving country names, programme names, publication titles and policy entities accurately. | https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/context_entities_recall/ |
| Topic Adherence | Whether output remains on the intended subject. | Typically measured by comparing generated content against topic constraints or labels. | Relevant when monitoring whether AI systems keep OECD answers focused on the correct policy issue. | https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/topic_adherence/ |
| Tool call Accuracy | Whether the model calls the correct tool with the correct parameters. | Correct tool calls / total tool-call opportunities. | Relevant because the role sits close to AI systems, automation and evaluation of how models interact with external sources. | https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/tool_call_accuracy/ |
| Agent Goal Accuracy | Whether an agent successfully completes the intended task. | Successful task completions / total evaluated tasks. | Useful for evaluating AI agents that search, summarise, monitor, or classify communication outputs. | https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/agent_goal_accuracy/ |
| Attack Success Rate (ASR) | How often adversarial prompts or attacks succeed. | Successful attacks / total attempted attacks. | Important background for any role dealing with trustworthy public AI systems and misinformation-sensitive environments. |  |
| Noise Sensitivity | How much performance degrades when the input is noisy or degraded. | Typically measured as the change in performance between clean and noisy input conditions. | Relevant for messy real-world content such as OCR text, imperfect transcripts, noisy media feeds or scraped web content. | https://www.amazon.science/publications/measuring-noise-vulnerability-in-nlp-models |
| Reject Rate (RR) | How often a model refuses to answer. | Rejected responses / total prompts. | Useful for understanding safety refusal behaviour and over-refusal trade-offs in public-facing AI systems. | https://sorry-bench.github.io/ |
| Amount of Leaked Information | How much private, confidential or protected information a system exposes. | Typically measured by the quantity or severity of sensitive information recovered during probing or extraction tests. | Relevant when evaluating privacy risk in AI systems handling OECD content, data or internal material. | https://arxiv.org/pdf/2403.00583.pdf |
| Anonymity Set Size | How many people remain indistinguishable within a dataset. | Count of records that share the same identifying pattern under the chosen quasi-identifiers. | Relevant as a privacy concept when communications intelligence work intersects with data governance. | https://link.springer.com/article/10.1007/BF00206326 |
| Equality of Opportunity Difference (EOD) | Difference in true positive rates across groups. | TPR of group A minus TPR of group B. | Important fairness metric for understanding whether an AI system performs unevenly across populations. | https://arxiv.org/abs/1811.05577 |
| Statistical Parity Difference (SPD) | Difference in positive outcome rates across groups. | Positive rate of group A minus positive rate of group B. | Important fairness metric in public-interest AI governance contexts. | https://arxiv.org/abs/1811.05577 |
| Conditional Demographic Disparity (CDD) | Demographic disparity measured after controlling for relevant context variables. | Group outcome differences are computed within matched or conditioned subgroups, then aggregated. | Useful when simpler fairness metrics are too crude for policy-relevant interpretation. | https://docs.aws.amazon.com/sagemaker/latest/dg/clarify-post-training-bias-metric-cddpl.html |
| Local Interpretable Model-agnostic Explanation (LIME) | Local explanation method that approximates model behaviour around one prediction. | Perturb the input locally and fit a simple interpretable surrogate model to approximate the black-box model near that case. | Important explainability method to know in any AI evaluation or governance conversation. | https://arxiv.org/abs/1602.04938 |
| Shapley Additive Explanation (SHAP) | Feature attribution method based on Shapley values. | Average each feature's marginal contribution across many possible feature coalitions. | Important explainability method for defensible interpretation of model outputs. | https://arxiv.org/abs/1705.07874 |
