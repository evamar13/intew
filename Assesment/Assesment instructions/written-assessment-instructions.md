## Guidelines

1. Find a quiet, comfortable place where you can focus without distractions.
2. The test is timed, and each question will show a clear time limit.
3. You'll upload a response document. Follow all format, file type, and content instructions.
4. Only one file may be uploaded; combine multiple files into a single ZIP archive if necessary.
5. Do not include personal information (e.g., name or email), as responses are reviewed anonymously.
6. During each activity, a proctoring feature will be active to ensure test integrity.
7. Unless specified otherwise, using books, the internet, or AI tools is strictly prohibited.
8. Plagiarism or external help will result in immediate disqualification.
9. Once a question starts, you cannot pause or return. Be ready before clicking `Get started`.
